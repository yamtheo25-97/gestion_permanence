Comment fonctionne le code d'accès

1. Configuration: L'administrateur définit un code numérique (ex: 1234)

2. Connexion utilisateur: Après avoir entré nom et prénom, l'utilisateur doit saisir le code

3. Vérification: Si le code est correct, l'utilisateur accède au système

4. Accès libre: Si aucun code n'est défini, l'accès est direct

5. Exception: L'administrateur (IFPB/END) n'a jamais besoin de code
